# Kanban Card

## Created With React + Vite

### Created By Mirul Moktadir Khan

A simple kanban project based on React, where you can add or delete task. Cllicking on the task, you can see the details of the task. This is only client side. 

### Package Used
- [React](https://react.dev/)
- [Tailwind-CSS](https://tailwindcss.com/)
